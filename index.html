06 / 12

Say this at the start
of any long task.

Start of any long task

Before you start, create a file in this folder called decisions.md.

Each time we settle something, add one line: what we decided, why, and what we ruled out and why.

Each time I correct you, add the correction and the reason I gave.

Read this file at the start of every session, and again any time you are unsure what we agreed.
